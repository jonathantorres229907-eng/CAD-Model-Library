This directory contains early prototype STL and SolidWorks part files generated during the initial development of the AI‑assisted CAD website. All models were produced using the same low‑poly generation prompt designed to create a rectangular block with an extruded tower. Because the backend geometry engine is still under development, the tower frequently collapsed inward due to incorrect positional logic and facet alignment. These files serve as a record of the system’s progression, illustrating how the generative pipeline handled prismatic shapes at different stages of refinement. As the project evolves, future versions will produce stable, watertight models suitable for full CAD workflows.
